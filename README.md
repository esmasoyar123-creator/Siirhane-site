# Şiirhane 1.0

Şiirhane, şiir severlerin şiirlerini paylaşabileceği modern ve responsive bir Next.js başlangıç projesidir.

## İçerik
- Ana sayfa ve hero alanı
- Günün Şiiri
- Kategori filtreleri
- Şiir arama
- Şiir paylaşma modalı
- Beğeni/kaydetme bildirimleri
- Tarayıcı localStorage ile eklenen şiirleri koruma
- Mobil uyumlu tasarım

## Çalıştırma
```bash
npm install
npm run dev
```

## Vercel
Projeyi GitHub'a yükleyip Vercel'de **New Project → Import Git Repository → Deploy** adımlarını kullanabilirsin.

## Sonraki aşama
Gerçek üyelik, veritabanı, şiir profilleri, yorumlar ve moderasyon sistemi eklenebilir.
